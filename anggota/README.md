# Folder Anggota

Setiap peserta menambahkan **satu file** berisi perkenalan di folder ini.
Ini adalah latihan pertama (Sesi 1) — tidak akan menimbulkan conflict karena setiap orang membuat file yang berbeda.

## Cara menambahkan

1. Salin `contoh-ahmad.md` menjadi `<nama-anda>.md` (huruf kecil, tanpa spasi).
   Contoh: `rina-lestari.md`
2. Ubah isinya dengan data Anda.
3. Commit, push, lalu buat Pull Request.

Lihat panduan lengkap di [`docs/SKENARIO.md`](../docs/SKENARIO.md).
